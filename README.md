# Real-Time Public Transport Tracking System

A hackathon-ready real-time public transport platform for small cities and tier-2 towns.

## 🚀 Tech Stack
- React + Vite + JavaScript
- Firebase Authentication & Cloud Firestore
- Leaflet / OpenStreetMap & Google Maps API abstraction
- Browser/device Geolocation API
- Tailwind CSS
